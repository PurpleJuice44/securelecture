포렌식 Level 9 장(chapter)

포렌식 CTF 실전

플래그 형식 단서부터 파일 복원까지 풀이한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 문제 파일 형식부터 판별
  • 문자열→메타→카빙 순서
  • 풀이 과정을 Write-up으로 기록

2. 핵심 개념

  • 문제 파일 형식부터 판별
  • 문자열→메타→카빙 순서
  • 풀이 과정을 Write-up으로 기록

2-2. 동작 원리 심화: 표준 풀이 파이프라인

포렌식 CTF는 매번 새로울 것 같지만, 정석 순서는 고정되어 있습니다. 형식 판별 → 문자열 → 메타데이터 → 카빙·심층 순으로, 쉬운 검사에서 어려운 검사로 내려가며, 각 단계 결과를 기록으로 남깁니다.

플래그 형식 확인"] --> F["file·xxd
진짜 형식 판별"] F --> S["strings
평문 단서 스캔"] S --> M["exiftool
메타데이터"] M --> B["binwalk·foremost
숨은 데이터"] B --> D{"플래그 발견?"} D -->|아니오| DP["심층: pcap·메모리·스테가
해당 장 기법 적용"] DP --> D D -->|예| W["Write-up 작성
재현 가능하게"]

읽는 법: 위에서 아래로가 기본 동선입니다. 한 단계에서 막히면 다음 단계로 넘어갔다가, 나중에 심층 기법으로 되돌아옵니다.

2-3. 문제 유형별 첫수

주어진 것첫 3수이어지는 장
이미지 1장file → strings → binwalkL7 스테가노그래피
pcap통계 → DNS Top → 객체 추출L6 네트워크 포렌식
디스크 이미지마운트 → 타임라인 → 카빙L3 디스크 이미징
메모리 덤프imageinfo → pslist → netscanL5 메모리 포렌식

3. 예제

file → strings → exiftool → binwalk 순서 적용

3-2. 심화 예제: 10분 풀이 루틴

# 0) 플래그 형식 메모 (예: FLAG{...}, CTF{...})
# 1) 형식 판별 (30초)
file chall.bin && xxd chall.bin | head -2
# 2) 문자열 스캔 (1분)
strings -n 6 chall.bin | grep -i -E "flag|ctf|http|pass" | head
# 3) 메타데이터 (1분)
exiftool chall.bin | head -20
# 4) 숨은 데이터 (2분)
binwalk -e chall.bin
# 5) 막히면 심층 분기: pcap이면 tshark, 덤프면 vol, 이미지면 zsteg

4. 실습

  1. 위 10분 루틴을 타이머를 켜고 그대로 수행한다.
  2. 각 단계 결과를 메모장에 붙여 넣어 풀이 로그를 만든다.
  3. 막힌 지점을 명시하고 심층 분기 중 하나를 선택해 적용한다.
  4. 플래그를 찾으면 역순으로(발견→근거→재현) Write-up을 쓴다.
  5. 다음 사람이 그대로 따라 할 수 있는지 읽어보며 다듬는다.

5. 퀴즈

  1. 풀이 순서를 말해본다
  2. Write-up에 남길 것은?
  3. 처음부터 심층 도구(volatility 등)를 쓰지 않는 이유는?
  4. 풀이 로그를 남기는 이유는?
  5. 플래그를 찾았는데 Write-up이 부실하면 생기는 문제는?
정답 보기
  1. 형식 판별 → 문자열 → 메타데이터 → 카빙·심층 순이다.
  2. 환경·명령·출력·막힌 지점·분기 판단까지 재현 가능한 전 과정을 남긴다.
  3. 저비용 검사로 풀리는 문제가 많아 시간을 아끼고, 심층 도구는 전제(프로파일 등)가 필요하기 때문이다.
  4. 막힌 지점 회귀와 팀 공유, 보고서 작성의 재료가 되기 때문이다.
  5. 재현·검증이 불가해 팀 점수·학습 효과가 증발한다. 풀이는 Write-up까지가 완성이다.

6. 흔한 실수

  • 플래그 형식 확인을 생략해 찾고도 못 알아보고 지나치는 경우
  • 한 도구에 집착해 파이프라인 다음 단계로 넘어가지 못하는 경우
