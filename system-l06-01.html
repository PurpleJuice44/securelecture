시스템 Level 6 장(chapter)

Windows 권한상승 점검

윈도우 점검 항목을 나열할 수 있다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • whoami /priv, systeminfo 패치 확인
  • AlwaysInstallElevated, 서비스 권한
  • 자격증명 저장소·공유폴더 점검

2. 핵심 개념

  • whoami /priv, systeminfo 패치 확인
  • AlwaysInstallElevated, 서비스 권한
  • 자격증명 저장소·공유폴더 점검

2-2. 동작 원리 심화: 윈도우 점검 지도

윈도우 권한상승 점검은 내 권한→패치 수준→설정 실수 순서로 봅니다. whoami /priv로 현재 권한을 확인하고, systeminfo로 미패치를 찾고, AlwaysInstallElevated·서비스 권한·자격증명 저장소를 차례로 점검합니다.

flowchart TD W["whoami /priv
현재 권한·그룹"] --> S["systeminfo
미패치 커널"] S --> A["AlwaysInstallElevated
레지스트리 2곳"] A --> V["서비스 권한
쓰기 가능 경로?"] V --> C["자격증명·공유
저장된 PW"] C --> R["보고·조치"]

읽는 법: 위에서 아래로가 점검 순서입니다. 권한 확인 없이 패치부터 보면 맥락을 놓칩니다.

2-3. 점검표

점검명령·위치위험 신호
권한whoami /privSeImpersonate 등 고위험
패치systeminfo오래된 빌드·누락 KB
AIEHKLM·HKCU Installer둘 다 1이면 취약
서비스sc qc 서비스명쓰기 가능 바이너리 경로

3. 예제

whoami /priv / systeminfo (실습 VM)

3-2. 심화 예제: 점검 루틴(실습 VM)

:: 1) 현재 권한과 그룹
whoami /priv
whoami /groups
:: 2) 패치 수준 (빌드·핫픽스)
systeminfo | findstr /B /C:"OS Name" /C:"OS Version"
wmic qfe get HotFixID | head
:: 3) AlwaysInstallElevated 2곳 확인
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
:: 4) 서비스 바이너리 권한 (예시)
sc qc spooler
icacls "C:\경로\service.exe"

4. 실습

  1. 점검 결과를 표로 정리한다.
  2. 고위험 권한 2개를 골라 의미를 적는다.
  3. AIE 2곳 값을 확인하고 판정한다.
  4. 서비스 경로 쓰기권한을 검사한다.
  5. 조치 우선순위를 매겨 보고한다.

5. 퀴즈

  1. UAC의 역할은?
  2. 서비스 권한이 약하면 생기는 일은?
  3. AIE가 둘 다 1이면 위험한 이유는?
  4. 패치 확인이 먼저인 이유는?
  5. 자격증명 저장소를 점검하는 이유는?
정답 보기
  1. 관리 작업 실행 시 동의를 구해 무단 상승을 막는 것이다.
  2. 서비스 바이너리 교체로 SYSTEM 권한을 탈취당한다.
  3. 일반 사용자가 MSI를 SYSTEM으로 설치할 수 있기 때문이다.
  4. 알려진 커널 익스플로잇이 통하면 나머지가 무의미하기 때문이다.
  5. 저장된 비밀번호가 평문에 준하게 복원되기 때문이다.

5-2. 한눈에 보는 점검 순서

sequenceDiagram participant A as 점검자 participant W as 윈도우 VM A->>W: whoami·systeminfo W-->>A: 권한·패치 현황 A->>W: AIE·서비스·자격증명 W-->>A: 취약 후보 A->>A: 조치·보고

읽는 법: 권한→패치→설정의 순서입니다. 설정만 보고 권한을 놓치면 판정이 어긋납니다.

6. 흔한 실수

  • HKLM만 보고 HKCU를 빼먹어 AIE를 오판하는 경우. 둘 다 1이어야 성립한다.
  • 실습 범위를 벗어난 도메인·운영망 점검. 절대 금지이다.
