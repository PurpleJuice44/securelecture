Write-up 작성법

풀이를 재현 가능하게 기록한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 문제 분류 → 관찰 → 가설 → 풀이 → 스크립트
  • 스크린샷+코드 포함
  • 실패 과정도 자산

2. 핵심 개념

  • 문제 분류 → 관찰 → 가설 → 풀이 → 스크립트
  • 스크린샷+코드 포함
  • 실패 과정도 자산

3. 예제

목차: 개요 → 분석 → 익스플로잇 → 교훈

4. 실습

풀이 1건을 Write-up으로 작성한다.
