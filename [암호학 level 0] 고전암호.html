암호학 Level 0 장(chapter)

고전 암호

시저 암호와 빈도분석을 체험한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 시저: 알파벳 밀기(키=이동 수)
  • 빈도분석으로 키 추측
  • 키 공간이 작으면 무차별대입 가능

2. 핵심 개념

  • 시저: 알파벳 밀기(키=이동 수)
  • 빈도분석으로 키 추측
  • 키 공간이 작으면 무차별대입 가능

3. 예제

KHOOR → 키 3 역이동 → HELLO

4. 실습

암호문 1개를 빈도분석으로 해독한다.
