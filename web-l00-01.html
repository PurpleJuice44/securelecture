웹 동작원리

브라우저가 서버와 대화하는 전체 흐름을 이해한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 클라이언트(브라우저)와 서버의 역할 구분
  • URL 입력부터 화면 표시까지: DNS→TCP→HTTP→렌더링
  • 정적 페이지와 동적 페이지의 차이

2. 핵심 개념

  • 클라이언트(브라우저)와 서버의 역할 구분
  • URL 입력부터 화면 표시까지: DNS→TCP→HTTP→렌더링
  • 정적 페이지와 동적 페이지의 차이

3. 예제

브라우저에 URL 입력 → DNS 조회 → TCP 연결 → HTTP 요청 → HTML 응답 → 렌더링

4. 실습

개발자도구 Network 탭에서 새로고침 후 요청 1개를 클릭해 Headers를 읽어본다.
