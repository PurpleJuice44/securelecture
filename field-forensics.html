🧬 포렌식

흔적을 추적하는 과학. 로그·디스크·메모리 분석.

분야 아키텍처: 증거의 생애주기

포렌식의 모든 활동은 아래 하나의 파이프라인으로 연결됩니다. 각 장(레슨)은 이 흐름의 한 구간을 담당합니다.

flowchart TD SRC["증거 원천
디스크·메모리·로그·네트워크"] --> ACQ["수집·보존
Write Blocker·이미징·해시"] ACQ --> STORE["보관연쇄
CoC 등록·봉인"] STORE --> AN["분석
파일·타임라인·복원"] AN --> COR["상관분석
로그+메모리+pcap 교차검증"] COR --> REP["보고·대응
IOC·타임라인·보고서"]

읽는 법: 위에서 아래로 증거가 이동합니다. 수집 단계에서 원본을 건드리면 아래 모든 단계의 신뢰도가 무너지므로, L0 증거보존이 전체의 토대가 됩니다.

학습 로드맵

기초 보존 원칙에서 시작해 매체별 분석 기법을 익히고, 실전 CTF와 보고서 작성으로 마무리합니다.

flowchart LR L0["L0 증거보존 원칙"] --> L1["L1 파일 시그니처"] L1 --> L2["L2 메타데이터"] L2 --> L3["L3 디스크 이미징"] L3 --> L4["L4 로그 분석"] L4 --> L5["L5 메모리 포렌식"] L5 --> L6["L6 네트워크 포렌식"] L6 --> L7["L7 스테가노그래피"] L7 --> L9["L9 CTF 실전"] L9 --> L10["L10 침해사고 보고서"]

읽는 법: 왼쪽부터 순서대로 학습하세요. L4~L6은 순서가 바뀌어도 무방하지만, L0은 반드시 가장 먼저 이수해야 합니다.
