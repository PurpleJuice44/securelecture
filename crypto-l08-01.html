암호학 Level 8 장(chapter)

해시 크랙 실습

사전공격으로 약한 비밀번호를 복원한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • john/hashcat 사용법
  • rockyou 사전 활용
  • 솔트·반복횟수가 방어력

2. 핵심 개념

  • john/hashcat 사용법
  • rockyou 사전 활용
  • 솔트·반복횟수가 방어력

2-2. 동작 원리 심화: 사전공격의 경제학

사람은 뻔한 비밀번호를 씁니다. 공격자는 자주 쓰는 목록(rockyou 등)으로 해시를 대입해봅니다. 솔트가 없고 빠르면 수십억 개를 순식간에 시험하므로, 약한 비밀번호는 즉시 뚫립니다.

flowchart TD H["유출 해시"] --> T{"형식 판별
길이·$접두>"} T --> J["john 실행
사전 대입"] T --> C["hashcat 실행
GPU 가속"] J --> R{"적중?"} C --> R R -->|예| P["평문 복원"] R -->|아니오| R2["규칙·증강 대입"]

읽는 법: 형식 판별→사전 대입→규칙 확장의 순서입니다. 솔트+느린 해시가 있으면 경제성이 무너집니다.

2-3. 도구·방어표

구분내용
johnCPU 사전·규칙 공격
hashcatGPU 고속 대입
rockyou.txt1400만 실제 유출 목록
방어솔트+bcrypt·argon2

3. 예제

john --wordlist=rockyou.txt hash.txt  (실습 해시만)

3-2. 심화 예제: 크랙 실습 루틴(실습 해시만)

# 1) 해시 형식 판별
hashid "5d41402abc4b2a76b9719d911017c592"  # 예시 MD5
# 2) john 사전 공격 (실습 해시 파일에만!)
john --wordlist=/usr/share/wordlists/rockyou.txt --format=Raw-MD5 hash.txt
john --show --format=Raw-MD5 hash.txt
# 3) hashcat GPU 공격 (모드 번호 확인)
# hashcat -m 0 hash.txt rockyou.txt  (0=MD5, 1000=NTLM, 1800=sha512crypt)
# 4) 방어 확인: 솔트·반복횟수 있는 형식 식별하기

4. 실습

  1. 실습 해시 1개를 크랙해본다.
  2. hashid로 형식을 먼저 판별한다.
  3. 사전 크기와 소요 시간을 기록한다.
  4. 솔트 있는 해시의 크랙 난이도를 비교한다.
  5. 방어 2종을 코드로 설명한다.

5. 퀴즈

  1. 사전공격의 원리는?
  2. 방어 2가지는?
  3. rockyou가 강력한 이유는?
  4. 솔트가 있으면 사전공격이 어려운 이유는?
  5. 무단 크랙이 불법인 이유는?
정답 보기
  1. 후보 목록의 해시를 미리 계산해 대조하는 것이다.
  2. 솔트와 느린 해시(bcrypt·argon2)이다.
  3. 실제 유출된 진짜 비밀번호들이라 적중률이 높기 때문이다.
  4. 후보마다 솔트를 붙여 다시 계산해야 해 표를 재사용할 수 없기 때문이다.
  5. 타인 계정 접근 시도 자체가 침해 행위이기 때문이다. 실습 해시만 다룬다.

5-2. 한눈에 보는 크랙 파이프라인

sequenceDiagram participant A as 분석가 participant I as 식별 participant C as 크래커 A->>I: 해시 형식 판별 I-->>A: 모드 번호 A->>C: 사전 대입 실행 C-->>A: 적중·실패 A->>C: 규칙 확장

읽는 법: 판별→대입→확장의 순서입니다. 판별을 틀리면 대입이 전부 헛수고가 됩니다.

6. 흔한 실수

  • 모드 번호를 틀려 엉뚱한 해시로 대입하는 경우
  • 실습 범위를 벗어난 해시를 다루는 경우. 절대 금지이다.
