Misc Level 4 장(chapter)

Wireshark 패킷 분석

필터로 원하는 패킷만 본다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 캡처 → 필터(http/dns/tcp.port)
  • Follow TCP Stream
  • IO 그래프로 이상 탐지

2. 핵심 개념

  • 캡처 → 필터(http/dns/tcp.port)
  • Follow TCP Stream
  • IO 그래프로 이상 탐지

2-2. 동작 원리 심화: 캡처→필터→재조립

Wireshark 분석은 전체를 잡고 필요한 것만 보고 대화로 복원합니다. 디스플레이 필터로 좁히고, Follow Stream으로 이어 붙이고, IO 그래프로 이상을 찾습니다.

flowchart TD C["캡처
인터페이스 선택"] --> F["필터
http·dns·ip.addr"] F --> S["Follow Stream
대화 복원"] S --> G["IO 그래프
급증 지점"] G --> E["파일 추출
Export Objects"]

읽는 법: 좁히기→잇기→훑기의 순서입니다. 처음부터 패킷을 하나씩 읽지 않습니다.

2-3. 필터표

목적필터
웹만http
도메인 조회dns
특정 호스트ip.addr==192.0.2.10
특정 포트tcp.port==80

3. 예제

http / dns / ip.addr==x 필터 실습

3-2. 심화 예제: tshark 루틴

# 1) 대화 통계
tshark -r cap.pcap -q -z conv,ip | head -20
# 2) DNS Top 5
tshark -r cap.pcap -Y dns -T fields -e dns.qry.name | sort | uniq -c | sort -nr | head -5
# 3) HTTP 호스트 Top
tshark -r cap.pcap -Y http -T fields -e http.host | sort | uniq -c | sort -nr | head
# 4) 특정 스트림 저장 후 Wireshark로 열기
tshark -r cap.pcap -Y "tcp.stream==0" -w s0.pcap

4. 실습

  1. DNS 질의 Top 5를 뽑아본다.
  2. HTTP 호스트 Top을 뽑는다.
  3. Follow Stream으로 대화 1개를 복원한다.
  4. IO 그래프에서 급증 구간을 찾는다.
  5. 추출 파일의 해시를 구한다.

5. 퀴즈

  1. 디스플레이 필터란?
  2. Follow Stream의 용도는?
  3. 캡처 필터와 디스플레이 필터의 차이는?
  4. IO 그래프가 보여주는 것은?
  5. 스트림 번호의 용도는?
정답 보기
  1. 잡힌 패킷 중 보여줄 것만 고르는 것이다.
  2. 흩어진 패킷을 대화로 이어 붙이는 것이다.
  3. 캡처 필터는 저장 대상을, 디스플레이는 표시 대상을 정한다.
  4. 시간대별 트래픽 양 변화이다.
  5. 대화를 구분하는 번호이다.

5-2. 한눈에 보는 분석 순서

sequenceDiagram participant A as 분석가 participant T as tshark participant W as Wireshark A->>T: 통계·Top 추출 T-->>A: 의심 대화 특정 A->>W: 스트림 재조립 W-->>A: 파일·대화 복원

읽는 법: 명령행으로 좁히고 GUI로 확인합니다. L6 포렌식 pcap 장과 이어집니다.

6. 흔한 실수

  • 필터 문법 오류로 빈 화면을 보고 데이터가 없는 줄 아는 경우
  • 암호화 구간을 평문처럼 해석하려 드는 경우
