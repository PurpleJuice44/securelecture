포렌식 Level 7 장(chapter)

스테가노그래피 분석

이미지 속 숨은 데이터를 찾는다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • binwalk로 첨부파일 탐지
  • zsteg/steghide로 LSB 검사
  • 끝에 덧붙은(zip) 데이터 확인

2. 핵심 개념

  • binwalk로 첨부파일 탐지
  • zsteg/steghide로 LSB 검사
  • 끝에 덧붙은(zip) 데이터 확인

2-2. 동작 원리 심화: 은닉 기법 3종

스테가노그래피는 덧붙이기·끼워넣기·바꾸기로 나뉩니다. 덧붙이기는 파일 끝에 데이터를 붙이는 단순 수법, 끼워넣기는 컨테이너 사이 빈틈을 쓰는 수법, 바꾸기는 픽셀 최하위 비트(LSB)를 살짝 고쳐 정보를 심는 수법입니다.

flowchart TD F["이미지 입수"] --> S["크기·형식 이상 확인
푸터 이후 데이터?"] S --> B["binwalk 스캔
덧붙은 파일 탐지"] B --> Z["zsteg·steghide
LSB 평면 검사"] Z --> E{"추출물 존재?"} E -->|예| D["추출·복호
패스워드 사전 대입"] E -->|아니오| A["통계 분석
chi-square·RS"]

읽는 법: 쉬운 것부터 순서대로 시도합니다. 덧붙이기가 가장 흔하므로 binwalk를 먼저, 그 다음 LSB 도구를 씁니다.

2-3. 도구별 역할

도구찾는 것명령 예시
binwalk덧붙은 파일·펌웨어binwalk -e img.png
zstegPNG LSB 평면zsteg -a img.png
steghideJPEG/BMP 은닉+암호steghide extract -sf img.jpg
strings평문 플래그·URLstrings -n 8 img.png

3. 예제

binwalk -e secret.png
zsteg secret.png | head

3-2. 심화 예제

# 1) 덧붙은 데이터 확인 (푸터 이후 바이트)
binwalk secret.png
xxd secret.png | tail -3
# 2) LSB 평면 전수 검사
zsteg -a secret.png 2>/dev/null | head -30
# 3) steghide (패스워드 필요 시 rockyou 사전 활용)
steghide extract -sf secret.jpg -p ""
# 4) 최후 수단: 문자열 긁기
strings -n 8 secret.png | grep -i -E "flag|ctf|http" | head

4. 실습

  1. binwalk로 덧붙은 zip이 있는지 확인하고 추출한다.
  2. zsteg -a로 LSB 평면을 검사해 숨은 문자열을 찾는다.
  3. 푸터 이후 바이트를 xxd tail로 직접 확인한다.
  4. steghide 추출 시 빈 패스워드→사전 순으로 시도한다.
  5. 발견 경로(도구·근거·추출물)를 순서대로 기록한다.

5. 퀴즈

  1. LSB 삽입이란?
  2. binwalk의 용도는?
  3. 덧붙이기와 LSB 삽입 중 탐지가 쉬운 쪽은? 이유는?
  4. steghide 추출에 패스워드가 필요할 때 시도 순서는?
  5. 이미지 크기가 같은데 용량이 비정상적으로 크면 무엇을 의심하는가?
정답 보기
  1. 픽셀 값의 최하위 비트를 바꿔 육안 변화를 최소화하며 데이터를 심는 기법이다.
  2. 파일 속 덧붙은 파일·펌웨어 등 숨은 구조를 찾아 추출하는 것이다.
  3. 덧붙이기이다. 푸터 이후 바이트가 그대로 보이므로 binwalk 한 번이면 드러나기 때문이다.
  4. 빈 문자열→문제 지문 단서→rockyou 등 사전 순으로 시도한다.
  5. 덧붙은 데이터나 고밀도 LSB 페이로드를 의심하고 binwalk·zsteg로 확인한다.

5-2. 한눈에 보는 은닉 탐지 흐름

sequenceDiagram participant A as 분석가 participant B as binwalk participant Z as zsteg participant S as steghide A->>B: 덧붙은 파일 스캔 B-->>A: 추출물 또는 없음 A->>Z: LSB 평면 검사 Z-->>A: 숨은 문자열 후보 A->>S: 암호 추출 시도 S-->>A: 페이로드 확정

읽는 법: 쉽고 흔한 덧붙이기부터 확인하고 LSB로 내려갑니다. 한 단계에서 멈추지 말고 다중 은닉까지 의심합니다.

6. 흔한 실수

  • JPEG에 zsteg를 돌리고 PNG에 steghide만 시도하는 등 형식-도구 매칭을 틀리는 경우
  • 추출된 zip에 또 이미지가 들어 있는 다중 은닉을 1단계에서 멈추는 경우
