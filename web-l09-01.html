웹 Level 9 장(chapter)

Burp Suite 실전 진단

프록시 가로채기와 Repeater 진단 흐름을 익힌다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • Proxy Intercept로 요청 가로채기
  • Repeater로 파라미터 변조 후 응답 관찰
  • Scope 설정 후 체크리스트 기반 전수진단

2. 핵심 개념

  • Proxy Intercept로 요청 가로채기
  • Repeater로 파라미터 변조 후 응답 관찰
  • Scope 설정 후 체크리스트 기반 전수진단

2-2. 동작 원리 심화: 프록시가 서는 위치

Burp는 브라우저와 서버 사이에 서서 모든 트래픽을 보고 고칩니다. 인증서를 심으면 TLS 안까지 들여다보고, Intercept로 멈추고, Repeater로 반복 실험합니다.

flowchart TD B["브라우저"] --> P["Burp Proxy
127.0.0.1:8080"] P --> I{"Intercept"} I -->|ON| H["요청 정지·수정"] I -->|OFF| S["서버로 전달"] H --> R["Repeater
변조·재전송"] R --> O["응답 비교
상태·길이·시간"] O --> L["발견표 기록"]

읽는 법: 가로채기→변조→관찰→기록의 루프입니다. Scope를 먼저 좁혀야 실습 범위를 벗어나지 않습니다.

2-3. 모듈별 역할

모듈용도 point
Proxy·Intercept요청 가로채기·수정실습 대상만 Intercept, 나머지는 통과
Repeater수동 변조·재전송원본 탭 복제 후 한 번에 하나씩 변경
Intruder자동 대입(페이로드 셋)허가 범위에서만, 스로틀 필수
Scope·Logger범위 제한·기록진단 시작 전 Scope 확정

3. 예제

Proxy → Intercept ON → Repeater(Ctrl+R) → 변조 → 관찰

3-2. 심화 예제: 전수진단 루틴(실습 앱)

# 1) 브라우저 프록시를 127.0.0.1:8080으로, Burp 인증서 설치
# 2) Target → Scope에 실습 도메인만 포함 (Include in scope)
# 3) 사이트를 한 바퀴 돌며 요청 수집 (Site map 완성)
# 4) 입력 파라미터마다 Repeater로 전송 → 따옴표·주석·태그 삽입
# 5) 응답 길이·상태·시간 변화를 발견표에 기록
# URL | 파라미터 | 페이로드 | 정상응답 | 변조응답 | 판정

4. 실습

  1. 실습 앱 1개를 전수진단하고 발견표(URL·파라미터·재현단계)를 작성.
  2. Scope 밖 요청이 섞이지 않았는지 Logger로 확인한다.
  3. 파라미터 1개당 최소 3종(따옴표·주석·태그)을 시험한다.
  4. 발견 1건을 재현 단계 5줄로 정리한다.
  5. 오탐 1건을 골라 왜 오탐인지 근거를 적는다.

5. 퀴즈

  1. Repeater의 용도는?
  2. Scope를 쓰는 이유는?
  3. Intercept를 켠 채 방치하면 생기는 일은?
  4. 응답 길이 변화가 힌트가 되는 경우는?
  5. 자동 스캔 전 수동 진단을 먼저 하는 이유는?
정답 보기
  1. 요청을 붙잡아 파라미터를 바꿔가며 재전송하고 응답을 비교하는 것이다.
  2. 진단 범위를 벗어난 무단 요청을 막고 노이즈를 줄이기 위해서이다.
  3. 모든 요청이 멈춰 브라우징이 마비되고, 타 사이트 요청까지 건드릴 위험이 있다.
  4. Blind 계열·인증 우회처럼 화면 차이가 결과인 경우이다.
  5. 비즈니스 로직·권한 문제는 자동 스캔이 못 찾고, 오탐을 걸러낼 기준이 필요하기 때문이다.

5-2. 한눈에 보는 진단 루프

sequenceDiagram participant A as 진단자 participant R as Repeater participant S as 서버 A->>R: 원본 요청 복제 R->>S: 파라미터 변조 전송 S-->>R: 응답 반환 R-->>A: 길이·상태·시간 비교 A->>A: 발견표 기록

읽는 법: 한 번에 하나씩만 바꿔 원인과 결과를 연결합니다. 여러 개를 동시에 바꾸면 무엇이 통했는지 알 수 없습니다.

6. 흔한 실수

  • Scope 설정 없이 진단해 실습 범위 밖을 건드리는 경우. 계약 위반이다.
  • Intruder를 무제한 속도로 돌려 서비스를 마비시키는 경우
