암호학 Level 4 장(chapter)

해시와 무결성

복원 불가 지문과 솔트의 역할을 이해한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • SHA-256: 같은 입력→같은 출력
  • 비밀번호는 해시+솔트로 저장
  • 무지개테이블 방어를 위한 솔트

2. 핵심 개념

  • SHA-256: 같은 입력→같은 출력
  • 비밀번호는 해시+솔트로 저장
  • 무지개테이블 방어를 위한 솔트

2-2. 동작 원리 심화: 지문의 3성질

해시는 임의 길이 입력을 고정 길이 지문으로 만듭니다. 좋은 해시는 역상 불가·충돌 저항·눈사태 효과(1비트 바뀌면 절반이 뒤집힘)를 가집니다. 비밀번호는 원문을 버리고 솔트+해시만 저장합니다.

flowchart TD I["입력
비밀번호"] --> S["솔트 결합
사용자별 난수"] S --> H["해시
SHA-256·bcrypt"] H --> D["DB 저장
솔트+해시"] L["로그인 시도"] --> H2["같은 계산"] H2 --> C{"저장값과 일치?"} C -->|예| OK["인증 성공"] C -->|아니오| NO["거부"]

읽는 법: 서버는 비밀번호를 모릅니다. 같은 계산을 해서 지문이 맞는지 볼 뿐입니다. 유출돼도 원문이 안 보이는 구조입니다.

2-3. 저장 방식 비교표

방식유출 시판정
평문 저장즉시 계정 탈취절대 금지
단순 해시무지개테이블 대입금지
솔트+해시개별 대입 필요최소선
bcrypt·argon2느린 계산으로 방어권장

3. 예제

echo -n hello | sha256sum

3-2. 심화 예제: 솔트 효과 체감

# 1) 같은 입력은 같은 출력 (결정성)
echo -n hello | sha256sum
echo -n hello | sha256sum
# 2) 1비트 차이의 눈사태 효과
echo -n Hello | sha256sum
# 3) 솔트 유무 비교 (개념)
python3 -c "import hashlib
pw='password123'
print(hashlib.sha256(pw.encode()).hexdigest())           # 무지개표에 있음
print(hashlib.sha256(('s@lt!'+pw).encode()).hexdigest()) # 표 무용지물"
# 4) bcrypt 권장 확인
python3 -c "import bcrypt; print(bcrypt.hashpw(b'pw', bcrypt.gensalt()))"

4. 실습

  1. 솔트 유무에 따른 저장값을 비교해본다.
  2. 같은 입력의 해시가 항상 같은지 확인한다.
  3. 대소문자 1개 차이의 출력을 비교한다.
  4. 무지개테이블 개념을 그림으로 설명한다.
  5. bcrypt 저장·검증 코드를 작성한다.

5. 퀴즈

  1. 솔트의 역할은?
  2. 해시를 복호화할 수 없는 이유는?
  3. 솔트를 공개해도 되는 이유는?
  4. bcrypt가 SHA-256보다 나은 이유는?
  5. 해시 충돌이 생기면 생기는 일은?
정답 보기
  1. 같은 비밀번호의 해시를 다르게 해 대량 대입표를 무용지물로 만드는 것이다.
  2. 단방향이라 역함수가 없고, 출력에서 입력을 되돌릴 수 없기 때문이다.
  3. 솔트 자체는 비밀이 아니라 개별화 장치이므로 공개돼도 대입 비용이 줄지 않기 때문이다.
  4. 의도적으로 느리고 솔트를 내장해 대입 공격 비용을 높이기 때문이다.
  5. 다른 입력이 같은 지문이 되어 무결성·인증이 깨진다.

5-2. 한눈에 보는 인증 흐름

sequenceDiagram participant U as 사용자 participant S as 서버 participant D as DB U->>S: ID·PW 제출 S->>D: 솔트 조회 D-->>S: 사용자 솔트 S->>S: 솔트+PW 해시 S->>D: 저장 해시와 비교 D-->>S: 일치 판정

읽는 법: 원문 비교가 아니라 계산 결과 비교입니다. DB가 털려도 원문이 안 보이는 이유입니다.

6. 흔한 실수

  • 솔트를 전 사용자 공용으로 쓰는 경우. 개별 난수가 원칙이다.
  • 빠른 해시(MD5·SHA1)를 비밀번호에 쓰는 경우
