암호학 Level 5 장(chapter)

ECB 모드 취약점

같은 평문은 같은 암호문이 되는 문제를 이해한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • ECB 펭귄 그림: 패턴이 그대로 노출
  • CBC/GCM 사용으로 대응
  • 절대 ECB에 이미지·구조적 데이터 금지

2. 핵심 개념

  • ECB 펭귄 그림: 패턴이 그대로 노출
  • CBC/GCM 사용으로 대응
  • 절대 ECB에 이미지·구조적 데이터 금지

2-2. 동작 원리 심화: 펭귄이 보이는 이유

ECB는 각 블록을 독립적으로 암호화합니다. 같은 평문 블록은 같은 암호문 블록이 되므로, 이미지의 윤곽·반복 패턴이 그대로 드러납니다. 유명한 ECB 펭귄 그림이 그 증거입니다.

flowchart TD P["평문 블록
P1·P1·P2"] --> E["ECB 암호화
각각 독립"] E --> C["암호문
C1·C1·C2"] C --> L["패턴 노출
같은 것은 같게"] P2["같은 평문"] --> E2["CBC·GCM
이전 결과와 엮음"] E2 --> C2["매번 다른 암호문"]

읽는 법: ECB는 같은 입력에 같은 출력이라 구조가 새고, CBC·GCM은 이전 블록과 엮어 구조를 지웁니다.

2-3. 모드 판정표

상황ECBCBC·GCM
같은 평문 반복들통남매번 다름
이미지 암호화윤곽 노출노이즈화
사용 여부금지조건부·권장

3. 예제

ECB 암호화 이미지의 윤곽 노출 (개념 그림)

3-2. 심화 예제: 반복 패턴 노출 실험

# 1) 같은 블록 반복 평문 준비 (16바이트 ×4 동일)
python3 -c "open('rep.bin','wb').write(b'A'*16*4)"
# 2) ECB 암호화 후 블록 비교 (앞 3블록이 같은지)
openssl enc -aes-128-ecb -K 00112233445566778899aabbccddeeff -iv 0 -in rep.bin -out ecb.bin
xxd -p -c 16 ecb.bin
# 3) CBC로 같은 실험 (전부 다름)
openssl enc -aes-128-cbc -K 00112233445566778899aabbccddeeff -iv 0102030405060708090a0b0c0d0e0f -in rep.bin -out cbc.bin
xxd -p -c 16 cbc.bin

4. 실습

  1. ECB/CBC 암호 결과를 비교 관찰한다.
  2. 반복 블록의 암호문 동일 여부를 표로 기록한다.
  3. 이미지 파일에 ECB를 적용해 윤곽을 확인한다(개념).
  4. CBC에 같은 실험을 해 차이를 적는다.
  5. 코드 속 ECB 사용처를 찾아 교체 방안을 적는다.

5. 퀴즈

  1. ECB의 문제점은?
  2. 대응 모드는?
  3. 펭귄 그림이 유명해진 이유는?
  4. 이미지·DB 같은 구조적 데이터에 ECB를 쓰면 안 되는 이유는?
  5. 레거시 ECB를 당장 못 바꾼다면 최소 조치는?
정답 보기
  1. 같은 평문 블록이 같은 암호문이 되어 패턴이 새기 때문이다.
  2. CBC·GCM이다.
  3. 암호화했는데도 그림이 보여 모드 선택의 중요성을 한눈에 보여주기 때문이다.
  4. 반복 구조가 암호문에 그대로 드러나 정보가 새기 때문이다.
  5. 신규는 GCM으로, 기존은 재암호화 계획을 세운다.

5-2. 한눈에 보는 모드 교체

sequenceDiagram participant D as 개발자 participant C as 코드베이스 D->>C: ECB 사용처 검색 C-->>D: 목록 확보 D->>C: GCM으로 교체 C-->>D: 테스트·재암호화 D->>D: 완료 보고

읽는 법: 찾아내기→바꾸기→다시 암호화하기의 순서입니다. 키·IV 관리도 함께 점검합니다.

6. 흔한 실수

  • ECB가 기본값인 라이브러리 설정을 그대로 쓰는 경우
  • 이미지 썸네일·압축 전 데이터에 ECB를 쓰는 경우
