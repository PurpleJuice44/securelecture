포렌식 Level 1 장(chapter)

파일 시그니처 분석

확장자가 아닌 매직바이트로 파일을 판별한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 매직바이트(앞 bytes)가 진짜 형식
  • file 명령으로 판별
  • 확장자 위조 탐지

2. 핵심 개념

  • 매직바이트(앞 bytes)가 진짜 형식
  • file 명령으로 판별
  • 확장자 위조 탐지

3. 예제

file mystery.bin
xxd mystery.bin | head -1

4. 실습

확장자를 바꾼 파일 2개를 판별해본다.

5. 퀴즈

  1. 매직바이트란?
  2. 확장자만 믿으면 안 되는 이유는?
