💥 포너블

메모리와 익스플로잇. BOF부터 ROP·Heap까지.

분야 아키텍처: 보호막을 벗기는 순서

포너블은 메모리 구조를 읽고, 보호기법을 하나씩 우회하며, 최종적으로 실행 흐름을 장악하는 분야입니다. 각 장은 이 사슬의 한 고리를 담당합니다.

flowchart TD M["메모리 구조
스택·힙·코드·rip"] --> B["BOF 기초
버퍼 넘침·복귀주소"] B --> R["RET 장악
rip 제어"] R --> S["셸코드
실행 코드 주입"] S --> NX["NX 우회·ROP
실행금지 뚫기"] NX --> A["ASLR 우회·릭
주소 알아내기"] A --> C["Canary 우회
스택 검사 뚫기"] C --> H["Heap 공략
UAF"] H --> K["커널 익스플로잇 개요"]

읽는 법: 위에서 아래로가 공격 사슬입니다. 앞 고리가 풀려야 다음 고리에 손이 닿습니다. L0 메모리 구조가 전체의 토대입니다.

학습 로드맵

메모리 읽기에서 시작해 고전 BOF를 익히고, 보호기법 우회를 거쳐 힙과 커널로 확장합니다.

flowchart LR P0["L0 메모리 구조"] --> P1["L1 BOF 기초"] P1 --> P2["L2 RET 덮기"] P2 --> P3["L3 셸코드"] P3 --> P4["L4 NX우회 ROP"] P4 --> P5["L5 ASLR 우회"] P5 --> P6["L6 Canary 우회"] P6 --> P7["L7 Heap 기초"] P7 --> P8["L8 UAF 활용"] P8 --> P9["L9 실전 pwn CTF"] P9 --> P10["L10 커널 익스 개요"]

읽는 법: 왼쪽부터 순서대로 학습하세요. L4~L6은 보호기법 우회 3종 세트로 묶어 이해하면 좋습니다.
