웹 Level 7 장(chapter)

Blind SQL Injection

응답이 없을 때 참/거짓과 시간으로 데이터를 추측한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • Boolean-based: 참/거짓 응답 차이 이용
  • Time-based: SLEEP() 지연으로 추측
  • SUBSTRING()으로 한 글자씩 추출 + 자동화 개념

2. 핵심 개념

  • Boolean-based: 참/거짓 응답 차이 이용
  • Time-based: SLEEP() 지연으로 추측
  • SUBSTRING()으로 한 글자씩 추출 + 자동화 개념

2-2. 동작 원리 심화: 대답 없는 상대에게 묻는 법

에러도 데이터도 안 보여주면, 예·아니오로 답할 수밖에 없는 질문을 던집니다. 참이면 정상 페이지, 거짓이면 빈 페이지(Boolean). 그것마저 막히면 응답 시간 차이로 답을 읽습니다(Time).

flowchart TD Q["에러·데이터 숨김 확인"] --> B["Boolean 시도
AND 1=1 vs 1=2"] B --> D{"응답 차이?"} D -->|예| E["SUBSTRING 한 글자씩
이진탐색 추출"] D -->|아니오| T["Time 시도
IF+SLEEP"] T --> M["지연 측정
참=5초·거짓=즉시"] E --> A["자동화 스크립트"] M --> A

읽는 법: Boolean이 되면 가장 빠르고, 안 되면 Time으로 갑니다. 한 글자씩 묻는 구조라 자동화가 필수입니다.

2-3. 추출 기법 비교

기법신호속도필요 조건
Boolean참·거짓 화면 차이빠름구분 가능한 응답
Time지연 시간느림SLEEP 계열 함수 허용
Out-of-band외부 DNS·HTTP 요청중간서버의 외부 통신 허용

3. 예제

' AND SUBSTRING(password,1,1)='a' --

3-2. 심화 예제: 수동→자동(실습 앱)

# 1) Boolean 판정 (id=7 기준)
id=7' AND 1=1 --     → 정상 (참)
id=7' AND 1=2 --     → 비정상 (거짓)
# 2) 첫 글자 추측 (a~z 순회)
id=7' AND SUBSTRING((SELECT password FROM users LIMIT 1),1,1)='a' --
# 3) Time 판정 (Boolean이 안 될 때)
id=7' AND IF(1=1,SLEEP(5),0) --     → 5초 지연
id=7' AND IF(1=2,SLEEP(5),0) --     → 즉시
# 4) 자동화cerpt (참거짓 함수만 교체하면 Time용)
import requests
def ask(payload):
    r = requests.get(URL, params={"id": payload}, timeout=10)
    return "정상문구" in r.text  # Boolean 판정자

4. 실습

  1. 참/거짓 입력에 대한 응답 차이를 표로 기록해본다.
  2. SUBSTRING으로 첫 글자 3개를 수동 추출한다.
  3. 이진탐색(중간값 비교)으로 질문 횟수를 줄여본다.
  4. Time 페이로드로 지연 차이를 스톱워치로 측정한다.
  5. 위 스크립트 골격에 한 글자 추출 루프를 완성한다.

5. 퀴즈

  1. Time-based 추출 원리는?
  2. 자동화 도구를 쓰기 전 수동으로 해야 할 것은?
  3. Boolean과 Time 중 먼저 시도하는 쪽은? 이유는?
  4. 이진탐색을 쓰는 이유는?
  5. sqlmap 사용 시 반드시 확인할 전제조건은?
정답 보기
  1. 조건 참일 때만 SLEEP으로 지연시켜 시간 차이로 참거짓을 읽는 것이다.
  2. 인젝션 판정과 응답 구분자(정상문구) 확보다. 자동화는 판정자를 먹고 산다.
  3. Boolean이다. 빠르고 네트워크 잡음에 강하기 때문이다.
  4. 한 글자당 질문을 26회에서 5회로 줄여 탐지를 피하고 속도를 올리기 위해서이다.
  5. 허가된 실습 범위·대상 확인이다. 무단 사용은 불법이다.

5-2. 한눈에 보는 추출 루프

sequenceDiagram participant S as 스크립트 participant W as 웹 서버 S->>W: SUBSTRING(pos,1)=X? W-->>S: 참·거짓 신호 S->>S: 다음 후보·위치 S->>W: 반복 W-->>S: 한 글자 확정

읽는 법: 위치와 후보 문자를 바꿔가며 묻는 루프입니다. 요청 간격을 두지 않으면 차단되므로 지연을 넣습니다.

6. 흔한 실수

  • 네트워크 지터를 참거짓으로 오판하는 경우. Time은 임계값+반복 확인이 필수이다.
  • 대소문자·공백을 무시하고 추출해 복원에 실패하는 경우
