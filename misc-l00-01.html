CTF 입문과 환경구축

CTF 방식과 실습 환경을 갖춘다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • Jeopardy(문제형) vs Attack-Defense
  • Kali/Ubuntu VM + 스냅샷
  • 플래그 형식 flag{...}

2. 핵심 개념

  • Jeopardy(문제형) vs Attack-Defense
  • Kali/Ubuntu VM + 스냅샷
  • 플래그 형식 flag{...}

2-2. 동작 원리 심화: CTF의 두 가지 경기

Jeopardy는 분야별 문제를 풀어 점수를 모으는 방식, Attack-Defense는 내 서버를 지키며 남을 뚫는 실시간 공방입니다. 입문은 Jeopardy부터, 환경은 격리 VM+스냅샷이 원칙입니다.

flowchart TD J["Jeopardy
웹·리버싱·포렌식 등 분야별 문제"] --> S["풀이
플래그 제출"] S --> P["점수·순위"] A["Attack-Defense
서버 공방전"] --> D["방어·공격 병행"] E["환경 구축
Kali·스냅샷"] --> J E --> A

읽는 법: 입문은 왼쪽(Jeopardy)부터입니다. 환경이 갖춰져야 어떤 문제든 안전하게 풀 수 있습니다.

3-2. 심화 예제: 첫날 세팅 루틴

# 1) VM 네트워크를 NAT·격리로 확인
# 2) 스냅샷 생성 (이름: clean-YYYYMMDD)
# 3) 기본 도구 점검
python3 --version; pip list 2>/dev/null | grep -i -E "requests|pwntools"

# 4) 웰컴 문제 풀이 후 스냅샷 복원 연습

4. 실습

  1. 웰컴 문제 1개를 풀이한다.
  2. 풀이 전후 스냅샷을 찍고 복원한다.
  3. 제출한 플래그 형식을 기록한다.
  4. 분야 7개를 한 줄씩 정리한다.
  5. 주간 학습 계획을 세운다.

5. 퀴즈

  1. Jeopardy란?
  2. 스냅샷이 필요한 이유는?
  3. Jeopardy와 Attack-Defense의 차이는?
  4. 플래그 형식을 먼저 확인하는 이유는?
  5. 격리 환경이 필요한 이유는?
정답 보기
  1. 분야별 문제를 풀어 점수를 모으는 방식이다.
  2. 오염된 환경을 즉시 되돌리기 위해서이다.
  3. Jeopardy는 문제 풀이전, AD는 실시간 공방전이다.
  4. 찾고도 못 알아보고 지나치는 일을 막기 위해서이다.
  5. 악성코드·공격 트래픽이 밖으로 새지 않게 하기 위해서이다.

5-2. 한눈에 보는 입문 흐름

sequenceDiagram participant L as 입문자 participant V as 격리 VM participant P as 플랫폼 L->>V: 환경 구축·스냅샷 V-->>L: 풀이 준비 완료 L->>P: 웰컴 문제 풀이 P-->>L: 점수·다음 문제

읽는 법: 환경→풀이→기록의 순서입니다. 기록 습관은 L8 Write-up으로 이어집니다.

6. 흔한 실수

  • 본인 PC에 도구를 깔고 푸는 경우. 격리가 원칙이다.
  • 어려운 문제부터 잡고 지치는 경우. 웰컴→쉬운 순이다.
