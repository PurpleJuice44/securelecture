리버싱 Level 0 장(chapter)

수와 어셈블리 맛보기

2진/16진과 어셈블리 3개 명령을 읽을 수 있다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 2진·16진 변환과 바이트 개념
  • mov(대입)/cmp(비교)/jmp(점프) 맛보기
  • CPU는 명령을 순서대로 실행한다

2. 핵심 개념

  • 2진·16진 변환과 바이트 개념
  • mov(대입)/cmp(비교)/jmp(점프) 맛보기
  • CPU는 명령을 순서대로 실행한다

2-2. 동작 원리 심화: CPU의 하루

CPU는 가져오기→해석→실행을 무한 반복합니다. 메모리에 적힌 2진수가 명령이 되고, mov는 값을 옮기고, cmp는 비교 흔적을 남기고, 조건 점프(je 등)가 흔적을 보고 갈림길을 선택합니다.

flowchart TD F["인출
eip 주소의 명령 읽기"] --> D["해석
mov·cmp·jmp 판별"] D --> E["실행
값 이동·비교"] E --> FL["플래그 기록
같음·큼·작음"] FL --> J{"조건 점프?"} J -->|예| T["목적지로 이동
eip 변경"] J -->|아니오| N["다음 명령
eip 증가"] T --> F N --> F

읽는 법: CPU는 생각하지 않고 이 고리만 돕니다. crackme의 정답 판정도 결국 이 고리 속 비교+점프입니다.

3. 예제

mov eax, 5 / cmp eax, 5 / je success

3-2. 심화 예제: 손으로 실행해보기

; 초기: eax=?, 플래그=?
mov eax, 5        ; eax=5
cmp eax, 5        ; 5-5=0 → ZF=1 (같음)
je success        ; ZF=1이므로 success로 점프
; ---
mov ebx, 3        ; ebx=3
cmp eax, ebx      ; 5-3≠0 → ZF=0
jne fail          ; ZF=0이므로 fail로 점프
# 16진수 계산기 없이 변환하기
# 0x41 = 4*16+1 = 65 = 'A'

4. 실습

  1. 0x41을 10진수·문자로 변환해본다.
  2. 위 예제의 각 줄마다 eax·ebx·ZF 값을 표로 적는다.
  3. je를 jne로 바꾸면 흐름이 어떻게 달라지는지 그린다.
  4. 0x30~0x39가 어떤 문자인지 외우지 말고 규칙으로 설명한다.
  5. 3줄짜리 비교·분기 프로그램을 직접 짜본다.

5. 퀴즈

  1. 0xFF는 10진수로?
  2. cmp 다음에 오는 명령의 역할은?
  3. ZF=1일 때 je와 jne 중 점프하는 쪽은?
  4. CPU가 명령을 찾는 기준 주소는 어디에 있는가?
  5. 0x41과 0x61의 관계는?
정답 보기
  1. 255이다.
  2. cmp가 남긴 플래그를 보고 분기한다.
  3. je이다. ZF=1은 같음을 뜻한다.
  4. eip 레지스터이다.
  5. 5번째 비트 하나 차이로 대·소문자가 갈린다.

5-2. 한눈에 보는 명령 사이클

sequenceDiagram participant C as CPU participant M as 메모리 C->>M: eip 주소 요청 M-->>C: 명령어 반환 C->>C: 해석·실행·플래그 기록 C->>M: eip 갱신 후 다음 요청

읽는 법: CPU와 메모리의 핑퐁이 프로그램의 전부입니다. 디버거는 이 핑퐁을 멈추고 엿보는 도구입니다.

6. 흔한 실수

  • cmp가 값을 바꾼다고 착각하는 경우. cmp는 빼보기만 하고 결과는 버린다.
  • 16진수를 외우려 드는 경우. 자리값(16의 거듭제곱) 계산이 본질이다.
