포너블 Level 4 장(chapter)

NX 우회와 ROP

실행 없이 코드조각을 이어 공격한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 가젯(ret으로 끝나는 명령 조각)
  • ret2libc: 라이브러리 함수 재사용
  • ROP 체인 = 주소들의 연속

2. 핵심 개념

  • 가젯(ret으로 끝나는 명령 조각)
  • ret2libc: 라이브러리 함수 재사용
  • ROP 체인 = 주소들의 연속

2-2. 동작 원리 심화: 실행 없이 실행하기

NX가 켜지면 스택 코드를 실행할 수 없습니다. 대신 이미 실행 가능한 코드 조각(가젯)들을 주소 나열로 이어 붙입니다. ret이 다음 가젯으로 점프하므로, 체인 전체가 프로그램처럼 동작합니다. 이미 있는 system 함수를 부르는 것이 ret2libc입니다.

flowchart TD G["가젯 수집
ROPgadget"] G --> P["pop rdi·ret
인자 세팅용"] G --> S["system 주소
libc"] G --> B["/bin/sh 문자열
libc"] P --> C["체인 조립
주소 나열"] S --> C B --> C C --> R["RET 덮기
체인 실행"]

읽는 법: 가젯은 레고 블록, 체인은 조립 설명서입니다. ret이 다음 블록으로 자동 이동시켜 전체가 실행됩니다.

2-3. 체인 구성표(x64 ret2libc)

순서스택 값효과
1pop rdi 주소다음 값을 rdi로
2/bin/sh 주소첫 인자 세팅
3system 주소system("/bin/sh") 호출

3. 예제

가젯 나열 → 체인 구성 (개념도)

3-2. 심화 예제: 가젯에서 체인까지(실습 VM)

# 1) 가젯 수집
ROPgadget --binary vuln | grep "pop rdi"
# 2) libc 주소 파악 (ASLR off 실습 환경)
ldd vuln | grep libc
# 3) 오프셋 계산 (readelf -s | grep system)
# 4) pwntools 체인 조립 개념
# payload = b"A"*offset + p64(pop_rdi) + p64(binsh) + p64(system)

4. 실습

  1. 가젯 3개를 찾아 용도를 적어본다.
  2. pop rdi 가젯의 주소를 기록한다.
  3. system·/bin/sh 주소를 구한다.
  4. 위 표 순서대로 체인을 조립한다.
  5. 셸 획득 여부를 확인하고 과정을 기록한다.

5. 퀴즈

  1. 가젯이란?
  2. ret2libc의 아이디어는?
  3. pop rdi 가젯이 필요한 이유는?
  4. 체인이 동작하는 원리는?
  5. NX가 있어도 ROP가 되는 이유는?
정답 보기
  1. ret으로 끝나는 짧은 기존 코드 조각이다.
  2. 새 코드 주입 없이 libc의 system 등 기존 함수를 재사용하는 것이다.
  3. x64 호출규약 첫 인자를 rdi에 넣어야 하기 때문이다.
  4. 각 가젯 끝의 ret이 다음 주소를 꺼내 점프하므로 연속 실행되기 때문이다.
  5. 실행 가능한 기존 코드만 쓰므로 실행 금지가 무의미해지기 때문이다.

5-2. 한눈에 보는 ROP 실행

sequenceDiagram participant A as 공격자 participant S as 스택 체인 participant C as CPU A->>S: 주소 나열 삽입 C->>S: ret→pop rdi S-->>C: rdi=/bin/sh C->>S: ret→system S-->>A: 셸 획득

읽는 법: ret이 도미노를 쓰러뜨립니다. 각 조각이 끝나면 다음 주소가 자동으로 실행됩니다.

6. 흔한 실수

  • 스택 정렬(16바이트)을 맞추지 않아 system 호출이 터지는 경우. ret 가젯 1개로 패딩한다.
  • ASLR이 켜진 주소를 그대로 쓰는 경우. L5 릭이 선행되어야 한다.
