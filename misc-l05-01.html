정규식 기초

로그·데이터에서 패턴을 추출한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • \d, \w, ., *, +, ^$
  • grep -E, python re
  • IP·이메일 패턴 작성

2. 핵심 개념

  • \d, \w, ., *, +, ^$
  • grep -E, python re
  • IP·이메일 패턴 작성

2-2. 동작 원리 심화: 패턴의 문법

정규식은 문자 지정·반복·위치 3요소로 이루어집니다. \d는 숫자, +는 1개 이상 반복, ^$는 줄의 시작·끝입니다. 로그에서 IP·이메일을 뽑는 것이 대표 용도입니다.

flowchart TD T["텍스트"] --> P["패턴 작성
문자+반복+위치"] P --> G["grep·re 실행"] G --> M{"매칭?"} M -->|예| E["추출·집계"] M -->|아니오| R["패턴 수정"]

읽는 법: 작게 시작해 넓혀갑니다. 탐욕 매칭(.*)이 길게 먹는 것이 대표 함정입니다.

2-3. 문법표

문법의미예시
\d숫자전화·IP 조각
\w영숫자·_ID·도메인
+·*1개 이상·0개 이상반복 구간
^·$시작·끝줄 전체 매칭
[ ]·( )집합·그룹추출 단위

3. 예제

grep -Eo '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' log

3-2. 심화 예제: 로그 채굴 루틴

# 1) IP 추출·집계
grep -Eo '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' access.log | sort | uniq -c | sort -nr | head
# 2) 이메일 추출
grep -Eo '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}' dump.txt | sort -u
# 3) 파이썬 추출 (그룹 활용)
import re
ips = re.findall(r"\d+\.\d+\.\d+\.\d+", open("access.log").read())
# 4) 탐욕 함정 확인: .* vs .*? 차이 비교

4. 실습

  1. 로그에서 IP를 추출해본다.
  2. 이메일 패턴을 작성·검증한다.
  3. 탐욕·게으른 매칭 차이를 실험한다.
  4. 추출 결과를 집계표로 만든다.
  5. 패턴 1개를 함수화해 재사용한다.

5. 퀴즈

  1. \d+의 의미는?
  2. ^와 $의 역할은?
  3. .*가 위험한 이유는?
  4. -o 옵션의 역할은?
  5. 정규식으로 HTML을 파싱하면 안 되는 이유는?
정답 보기
  1. 숫자 1개 이상이다.
  2. 문자열의 시작·끝 고정이다.
  3. 탐욕적으로 최대로 먹어 의도와 다르게 매칭되기 때문이다.
  4. 매칭된 부분만 출력하는 것이다.
  5. 중첩 구조를 정규식으로 온전히 다룰 수 없어 깨지기 때문이다.

5-2. 한눈에 보는 추출 흐름

sequenceDiagram participant A as 분석가 participant R as 정규식 엔진 A->>R: 작은 패턴 투입 R-->>A: 매칭 샘플 A->>R: 패턴 정교화 R-->>A: 추출·집계

읽는 법: 한 번에 완성하지 않고 샘플을 보며 조입니다. 테스트용 문자열 모음이 필수입니다.

6. 흔한 실수

  • 이스케이프(\.)를 빼먹고 아무 문자나 매칭되는 경우
  • 한글·유니코드를 \w로 다 된다고 착각하는 경우
