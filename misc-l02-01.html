자동화 스크립팅

반복 작업을 스크립트로 해결한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • for + try로 무차별 대입 자동화 개념
  • 딜레이·에러처리 예절
  • 결과 로깅

2. 핵심 개념

  • for + try로 무차별 대입 자동화 개념
  • 딜레이·에러처리 예절
  • 결과 로깅

2-2. 동작 원리 심화: 손풀이의 한계 넘기

같은 시도를 수백 번 해야 하면 for+try 루프로 넘깁니다. 후보를 돌리고, 실패는 넘기고, 성공하면 멈추고 기록합니다. 예절(딜레이·범위 준수)이 없으면 공격이 되므로 실습 대상에만 씁니다.

flowchart TD W["단어장·후보 생성"] --> L["for 루프
하나씩 시도"] L --> T["try 요청
타임아웃 포함"] T --> S{"성공?"} S -->|예| R["기록·종료"] S -->|아니오| D["딜레이·다음"]

읽는 법: 루프→시도→판정의 반복입니다. 딜레이와 로깅이 빠지면 스크립트가 아니라 사고가 됩니다.

2-3. 예절표

예절이유
실습 대상만무단 대입은 불법
딜레이 삽입서버 부하·차단 방지
try·타임아웃멈춤 방지
결과 로깅재현·보고

3. 예제

for pw in wordlist: try_login(pw) (개념, 실습 대상만)

3-2. 심화 예제: 대입 스크립트 골격(실습 대상만)

import requests, time
URL = "http://실습호스트/login"  # 허가된 실습 대상만!
for pw in open("mini.txt"):
    pw = pw.strip()
    try:
        r = requests.post(URL, data={"id": "test", "pw": pw}, timeout=5)
        print(pw, len(r.text))
        if "성공문구" in r.text:
            print("FOUND:", pw); break
    except Exception as e:
        print("ERR", e)
    time.sleep(0.2)  # 예절 딜레이

4. 실습

  1. 단어장 대입 스크립트를 작성한다(실습).
  2. 딜레이 유무의 차이를 기록한다.
  3. 타임아웃·예외 처리를 넣는다.
  4. 결과 로그를 파일로 남긴다.
  5. 성공 조건 판정자를 명시한다.

5. 퀴즈

  1. 자동화가 필요한 경우는?
  2. 실습 예절 2가지는?
  3. 딜레이가 필요한 이유는?
  4. 타임아웃 없이 돌리면 생기는 일은?
  5. 성공 판정자를 먼저 정해야 하는 이유는?
정답 보기
  1. 같은 시도를 대량 반복해야 할 때이다.
  2. 실습 대상 준수와 딜레이이다.
  3. 서버 부하·차단을 피하기 위해서이다.
  4. 멈춘 요청에 전체가 묶인다.
  5. 판정 기준 없이 돌리면 성공을 지나치기 때문이다.

5-2. 한눈에 보는 자동화 루프

sequenceDiagram participant S as 스크립트 participant T as 실습 대상 S->>T: 후보 전송 (딜레이) T-->>S: 응답 반환 S->>S: 성공 판정·로깅 S->>T: 다음 후보

읽는 법: 전송→판정→기록의 고리입니다. 실습 범위를 벗어나면 즉시 중단합니다.

6. 흔한 실수

  • 실습 대상 확인 없이 돌리는 경우. 절대 금지이다.
  • 로그 없이 돌려 성공을 놓치는 경우
