Misc Level 3 장(chapter)

OSINT 기초

공개정보로 단서를 수집한다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 도메인·이메일·메타데이터 수집
  • 허위정보 교차검증
  • 개인정보 취급 윤리

2. 핵심 개념

  • 도메인·이메일·메타데이터 수집
  • 허위정보 교차검증
  • 개인정보 취급 윤리

2-2. 동작 원리 심화: 공개정보 수집 지도

OSINT는 도메인→사람→파일로 넓혀갑니다. whois·DNS로 주인을 찾고, 검색·SNS로 사람을 찾고, 문서 메타데이터로 흔적을 찾습니다. 모든 정보는 교차검증하고, 개인정보는 다루지 않습니다.

flowchart TD D["도메인
whois·DNS"] --> P["사람
검색·SNS"] P --> F["파일
메타데이터"] F --> V["교차검증
2개 출처 이상"] V --> R["보고 (공개정보만)"]

읽는 법: 한 출처의 주장은 가설입니다. 두 곳에서 맞을 때만 사실로 씁니다.

2-3. 수집 항목표

대상도구·명령얻는 것
도메인nslookup·whoisIP·등록정보
웹검색 연산자노출 문서·히스토리
파일exiftool작성자·시각

3. 예제

nslookup / whois 관찰 (공개정보)

3-2. 심화 예제: 도메인 조사 루틴(공개정보)

# 1) DNS·등록정보 (수동 타이핑 금지, 복사 사용)
nslookup example.com
whois example.com | head -30
# 2) 검색 연산자로 노출면 조사
# site:example.com filetype:pdf
# "example.com" -site:example.com
# 3) 메타데이터는 L2 포렌식 기법과 연결
# 포인트: 개인정보·비공개 접근은 절대 금지

4. 실습

  1. 도메인 1개의 공개정보를 정리한다.
  2. 출처 2곳 이상으로 교차검증한다.
  3. 수집 항목을 표로 만든다.
  4. 개인정보 포함 시 마스킹한다.
  5. 출처를 명시한 보고서를 쓴다.

5. 퀴즈

  1. OSINT의 범위는?
  2. 윤리 주의점은?
  3. 교차검증이 필요한 이유는?
  4. whois로 보는 정보는?
  5. 수집 금지선은?
정답 보기
  1. 공개된 정보만이다. 비공개 접근·탈취는 제외이다.
  2. 개인정보 최소 수집·마스킹·목적 외 사용 금지이다.
  3. 허위·오래된 정보가 섞여 있기 때문이다.
  4. 등록자·네임서버·만료일 등이다.
  5. 로그인 우회·비공개 자료 접근이다.

5-2. 한눈에 보는 수집 흐름

sequenceDiagram participant A as 조사자 participant D as 공개 출처 A->>D: 도메인 조회 D-->>A: 등록·DNS 정보 A->>D: 검색·문서 조사 D-->>A: 단서 수집 A->>A: 교차검증·보고

읽는 법: 조회→수집→검증의 순서입니다. 검증 없는 수집은 소문 수집과 같습니다.

6. 흔한 실수

  • 단일 출처를 사실로 보고하는 경우
  • 개인정보를 보고서에 그대로 싣는 경우
