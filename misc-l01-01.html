파이썬 기초

CTF 풀이용 파이썬을 쓸 수 있다.

⚠️ 실습은 본인 소유 VM·실습용 사이트(허가된 환경)에서만 수행하세요.

1. 학습 목표

  • 입출력·반복문·함수
  • 문자열/바이트 다루기
  • requests로 HTTP 요청

2. 핵심 개념

  • 입출력·반복문·함수
  • 문자열/바이트 다루기
  • requests로 HTTP 요청

2-2. 동작 원리 심화: CTF 파이썬 3종 세트

CTF 파이썬은 문자열·바이트·요청이면 절반이 끝납니다. 인코딩을 풀고, 바이트를 자르고 붙이고, HTTP로 보내고 받는 흐름이 모든 풀이 스크립트의 뼈대입니다.

flowchart TD S["문자열 처리
슬라이싱·정규식"] --> B["바이트 변환
encode·decode·hex"] B --> R["requests 요청
GET·POST"] R --> P["응답 파싱
플래그 추출"]

읽는 법: 문자열→바이트→요청→파싱의 순서입니다. 막히면 앞 단계의 타입(str·bytes)부터 의심합니다.

2-3. 필수 스니펫표

용도코드
base64 디코딩base64.b64decode(s)
hex 변환bytes.fromhex(h)
HTTP GETrequests.get(url).text
반복 대입for c in string.printable

3. 예제

requests.get(url).text (개념)

3-2. 심화 예제: 풀이 상자 3종

# 1) base64 다중 디코딩
import base64
def autodecode(s, n=5):
    for _ in range(n):
        try: s = base64.b64decode(s).decode()
        except Exception: break
    return s
# 2) HTTP 요청·파싱
import requests, re
r = requests.get(url, timeout=10)
print(re.findall(r"flag\{[^}]+\}", r.text))
# 3) 문자-바이트 왕복
b = "ABC".encode()        # b'ABC'
print(b.hex(), b[0])      # 414243 65

4. 실습

  1. base64 디코딩 스크립트를 작성한다.
  2. 위 3종 스니펫을 손으로 쳐본다.
  3. str·bytes 타입 에러를 일부러 내보고 고친다.
  4. 실습 URL에서 플래그 패턴을 추출한다.
  5. 자주 쓰는 코드를 함수 파일로 모은다.

5. 퀴즈

  1. 바이트와 문자열 차이는?
  2. requests의 용도는?
  3. .encode()와 .decode()의 방향은?
  4. 타임아웃을 거는 이유는?
  5. 스크립트를 함수화하는 이유는?
정답 보기
  1. 바이트는 날것(0~255), 문자열은 해석된 문자이다.
  2. HTTP 요청·응답을 다루는 것이다.
  3. encode는 문자열→바이트, decode는 바이트→문자열이다.
  4. 멈춘 요청에 풀이가 묶이지 않게 하기 위해서이다.
  5. 다음 문제에 그대로 재사용하기 위해서이다.

5-2. 한눈에 보는 풀이 스크립트 흐름

sequenceDiagram participant S as 스크립트 participant W as 문제 서버 S->>S: 입력 가공 (디코딩) S->>W: 요청 전송 W-->>S: 응답 수신 S->>S: 정규식 추출

읽는 법: 가공→요청→추출의 고리입니다. 이 고리가 L2 자동화의 재료가 됩니다.

6. 흔한 실수

  • 개행·공백을 안 떼고 디코딩해 실패하는 경우. strip()이 먼저이다.
  • 예외 처리 없이 돌려 중간에 멈추는 경우
